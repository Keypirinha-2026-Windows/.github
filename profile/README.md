# Project Overview

Keypirinha is a fast keyboard-driven application launcher for Windows. It provides a searchable interface for launching applications, opening files and folders, accessing bookmarks, performing calculations, and running other commands without navigating through traditional Windows menus.

The launcher is designed around keyboard input and can be extended through a package and plugin system. This allows additional functionality to be integrated into the same quick-search interface.

The latest official release is **Keypirinha v2.26**. The project provides both installed and portable distributions for Windows.

---

# Application & File Launcher

Keypirinha can index installed applications and make them available through its launcher interface.

Users can begin typing the name of an application, file, folder, or other indexed item and select the desired result from the list.

The keyboard-first design makes frequently used programs accessible without manually browsing the Start menu or desktop.

Keypirinha can also be used to launch documents, folders, URLs, and other supported items.

---

# Search, Catalog & Actions

Keypirinha maintains a searchable catalog containing items provided by its built-in functionality and installed packages.

Search results can provide multiple actions depending on the selected item. These actions can include opening, copying, editing, or passing information to another supported command.

The launcher is designed to remain responsive while searching through available items, making it suitable for frequently repeated desktop workflows.

---

# Calculator & Productivity Tools

Keypirinha includes built-in functionality for common productivity tasks.

The launcher can perform calculations and provide quick access to frequently used resources without requiring a separate calculator application.

Additional packages can expand the available functionality with specialized search providers, commands, bookmarks, documentation tools, and other utilities.

---

# Plugins & Package System

One of Keypirinha's main features is its extensible package architecture.

Plugins can add new catalog items, search providers, commands, and other functionality to the launcher. Third-party packages can therefore extend Keypirinha beyond its built-in capabilities.

Packages are supported through Keypirinha's package directories and can be installed manually or through compatible package-management tools.

Because third-party packages execute code within the application environment, they should be obtained from trusted sources and checked for compatibility before installation.

---

# Portable & Installed Modes

Keypirinha is available in both portable and installed configurations.

The portable version can be extracted to a chosen directory and used without a traditional system installation. This can be useful when maintaining a self-contained launcher configuration.

Installed mode stores application data in the user's Windows profile and integrates more traditionally with the operating system.

The two modes allow users to choose between portability and a conventional Windows installation.
